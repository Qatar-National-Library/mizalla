{# Shared UI fragments. ``breadcrumb`` renders a semantic breadcrumb trail. Items are ``(label, href)`` pairs; the final item is rendered as the current page and is not a link. A trail of one or fewer items is suppressed: there is no hierarchy to express on a top-level screen such as the portfolio, About or sign-in, and the persistent top bar already provides the way home. ``app_switcher`` renders the grant-gated service links, so the desktop bar and the mobile menu cannot drift apart. It is called twice per page - once for each - so it takes the member rather than reaching for ``current_user`` itself. ``accordion`` wraps a section in a native
element. Native disclosure controls are keyboard accessible and keep working with JavaScript disabled, so no script is involved. Pass ``open=True`` for the one section that should start expanded. ``role_groups`` renders one group per role, each with the people holding it. The project screen shows the same membership rows in three places - the delivery team, the external contacts, and the full role map - so the row markup lives here once rather than three times. ``can_manage_members`` is passed in rather than computed: whether the *current* member may change this project's roster is decided by :func:`is_project_pm`, not by anything visible in the group. #} {% macro admin_nav(active_page) %}
