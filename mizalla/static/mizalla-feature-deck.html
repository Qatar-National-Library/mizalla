11 / AI SERVICES

Three Azure tools.
Granted one member at a time.

An administrator ticks each service per member. The gate is enforced on the server, not by hiding links, so a typed URL for an ungranted service returns 403.

02

03

Chat — documents in, cited answers out. Keyword retrieval, no embeddings.
